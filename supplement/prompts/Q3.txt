Create a graphical user interface (GUI) in MATLAB for simulating GPS technology dynamics. Requirements: (1) display GPS-related equations (e.g., pseudorange equation, position calculation) using LaTeX rendering inside the GUI; (2) show and explain the MATLAB functions used to implement the equations; (3) implement a dynamic simulation of GPS signal reception and positioning, animating satellite positions and user movement in 3D and updating pseudorange lines and user position in real time; (4) comment each section of the code (GUI design, LaTeX integration, simulation logic, visualization).
