the least-squares position update

MATLAB functions explained: The "MATLAB Functions" tab has a list of the functions that implement the equations. Selecting one shows an explanation and the key lines of its code. The functions are satECEF, visibility, pseudoranges, solveGPS, the DOP calculation, ecef2enuRot and the animation loop.
Dynamic simulation:
24 satellites orbit a 3D Earth in the ECEF frame, and Earth rotation is included.
The user moves along a chosen speed and heading, leaving a trail.
Pseudorange lines are drawn only to satellites above the elevation mask.
Each frame generates noisy measurements and solves the 4-unknown least-squares fix.
The estimated position is shown as a magenta ×.
A live readout and a plot of position error and PDOP over time are updated each frame.
Commented code: The file is split into seven labelled sections: constants, GUI design, LaTeX integration, function documentation, visualization, simulation logic and the math functions.

Controls: Start/Pause and Reset buttons, plus sliders for time step, user speed, heading, range noise, receiver clock bias and elevation mask. You can also rotate the 3D view with the mouse while it runs.

Simplifications: The Earth is a sphere and the orbits are circular. There are no ionosphere, troposphere or ephemeris errors, only Gaussian noise and a constant clock bias. The user starts at a fixed 30°N, 100°E, which you can change in resetState().

    function stepSim()                    % ONE simulation step
        dt   = get(sWarp,'Value');        % simulated seconds per frame
        simT = simT + dt;

        v  = get(sSpeed,'Value');  az = deg2rad(get(sHead,'Value'));
        lat = lat + v*dt*cos(az)/Re;
        lat = max(min(lat,deg2rad(80)),-deg2rad(80));
        lon = lon + v*dt*sin(az)/(Re*cos(lat));
        drawFrame();
    end

function S = satECEF(t,orb)
% Satellite positions in ECEF at time t [s]  (circular orbits).
%   u = u0 + n t ;  r_ECI = Rz(Omega) Rx(i) [R cos u; R sin u; 0]
%   r_ECEF = Rz(-omegaE t) r_ECI
u  = orb.u0 + orb.n*t;
ci = cos(orb.inc);  si = sin(orb.inc);
x  = orb.R*(cos(orb.Omega).*cos(u) - sin(orb.Omega).*ci.*sin(u));
y  = orb.R*(sin(orb.Omega).*cos(u) + cos(orb.Omega).*ci.*sin(u));
z  = orb.R*si.*sin(u);
th = orb.omegaE*t;                                  % Earth rotation angle
S  = [ x*cos(th) + y*sin(th); ...
      -x*sin(th) + y*cos(th); ...
       z ];
end
 
function [vis,el] = visibility(S,ru,maskDeg)
% Elevation angle of every satellite and visibility flag.
up = ru/norm(ru);                       % local vertical (spherical Earth)
d  = S - ru;                            % line-of-sight vectors
r  = sqrt(sum(d.^2,1));
el = asind((up'*d)./r);                 % elevation [deg]
vis = el >= maskDeg;
end
 
function rho = pseudoranges(Sv,ru,biasM,sigma)
% Pseudorange equation: rho_i = ||s_i - u|| + c*dt + eps_i
r   = sqrt(sum((Sv - ru).^2,1))';       % geometric ranges (column)
rho = r + biasM + sigma*randn(size(r)); % add clock bias [m] and noise
end
 
function [x,Q] = solveGPS(Sv,rho)
% Iterative least-squares solution for x = [X; Y; Z; b], b = c*dt.
n = numel(rho);
x = [0;0;0;0];                          % start at Earth centre
for k = 1:10
    d = Sv - x(1:3);                    % 3xn
    r = sqrt(sum(d.^2,1))';             % predicted ranges
    H = [-(d./r')', ones(n,1)];         % geometry matrix (n x 4)
    dRho = rho - (r + x(4));            % measurement residual
    dx = H\dRho;                        % least-squares step
    x  = x + dx;
    if norm(dx(1:3)) < 1e-4, break; end
end
Q = inv(H'*H);                          % cofactor matrix -> DOP
end
 
function R = ecef2enuRot(lat,lon)
% Rotation matrix from ECEF to local East-North-Up.
sl = sin(lat); cl = cos(lat); so = sin(lon); co = cos(lon);
R = [-so,      co,     0; ...
     -sl*co, -sl*so,  cl; ...
      cl*co,  cl*so,  sl];
end
