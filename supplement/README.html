Using the archive

Response captures, generated code, evaluation copies, reference calculations and desktop records are organized by task and assistant. Historical progress logs are retained; the adjudicated results in S2–S4 take precedence over earlier pending-status notes.

Run a fresh evaluation in a separate copy, because the checkers write result files. GUI evaluation requires direct observation of animation and callbacks. See the reproduction instructions.

Local paths and private conversation identifiers have been redacted. Original and distributed hashes are recorded in the export manifest; checksums verify the distributed files. Read the data provenance and reuse notes for details.

Missing observations remain missing. Initialization, field agreement and dynamic behavior are distinct outcomes.
