# From Plausible to Verified: Evaluating GenAI-Generated MATLAB Code in Electromagnetics Education

Supplementary data, MATLAB code and desktop observations for the study.

The collection contains 72 initial responses: 61 code-bearing outputs and 11 no-code service messages.
The archived pilot is reported separately.

## Study materials

- [Study website](index.html): methods, field results, GUI observations and the six experimental prompts.
- [Supplement guide](supplement/README.html): protocols, data and reproduction instructions.
- [Download supplementary data](supplement.zip): the complete data package.

At the tested inputs, reference agreement was confirmed for 21/22 available point-charge files, 21/21 finite-wire files and 7/9 self-check files. Five of nine initial GUIs initialized. All four separate repairs initialized, but complete dynamic functionality was not established.
